## 2. Socket → Bufio（上层网络提供接口）

### 2.1 核心设计
```cpp
// 上层网络（HttpServer/LinkServer/WS/MQTT/CoAP）提供可选配置：
struct NetIoConfig {
  bool use_bufio = false;           // 默认？见 2.2
  BatchConfig batch = kDefaultBatch;  // kHybrid + max_batch 16
};
// Socket → Bufio 转换
bufio::Reader reader(socket);   // 或 socket.MakeBufioReader(config)
bufio::Writer writer(socket);   // 可选 batch 配置
```

### 2.2 默认配置
- **Bufio 默认开启还是关闭？**——需要测：协议层用 bufio 后吞吐/延迟是否改善（HTTP 小响应/Link 小包）；默认值按测试结果定；
- **Bufio 配置可改**：FlushPolicy（4 种）+ max_batch + threshold + interval。

### 2.3 实现点
- Socket 提供 `MakeBufioReader/MakeBufioWriter(config)`（或 bufio 的构造函数直接接 Socket）；
- 协议层读写改走 bufio（可选）；
- bufio::Writer 的 WriteBatch 适配器 → Socket::send_batch（sendmmsg）；
- 文件传输用 Socket::send_file（sendfile）。

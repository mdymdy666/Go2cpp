## 三、审查时的通用检查（每个类都过一遍）

- [ ] **条件变量**：`wait` 谓词 atomic/同锁 + `while`；`notify` 在锁内；有超时或 cancel；
- [ ] **资源**：fd/内存/线程的释放点明确（构造↔析构对称）；
- [ ] **`[[nodiscard]]`**：调用方检查；
- [ ] **边界**：空/超长/畸形输入不越界；
- [ ] **状态机**：每个转移有 `file:line` 依据。

## 三、当前阻塞与替代方案

| 阻塞 | 影响 | 当前替代 |
|---|---|---|
| REQ-004 / 011 / 012 未实现 | 无法用 Go2Cpp 做 RDRL/RDCH 编解码 | JinShan 产品仓库自带 `product/common/rdrl`（C++ 实现，28/28 单测通过） |
| REQ-005 / 006 未实现 | 无法用 Go2Cpp 做配对表与中继 | `product/relay`（Go 实现，93 PASS / 1 SKIP）已自建 |
| REQ-009 Go 风格 API 进行中 | 迁移成本待评估 | 产品侧先定义 `rd::net` 适配层（R-040），不直接绑 `go2cpp::platform` |

**结论**：Go2Cpp 交付前，JinShan 用自建实现推进，不阻塞主线；交付后按 `rd::net` / `rd::sync` 接口逐个替换实现，调用方不改。
